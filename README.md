# Coin Change — расчёт сдачи минимальным количеством монет

🇷🇺 Русский · [🇬🇧 English](README.en.md)

Консольная программа на Python: находит минимальное количество монет заданных номиналов для выдачи сдачи (**жадный алгоритм**), умеет работать через консоль и через файлы, а также создавать резервные копии и восстанавливать кассовые настройки.

## Описание программы

- Расчёт сдачи по номиналам из `config/settings.json` (по умолчанию 10, 5, 2, 1).
- Ввод: интерактивное меню, аргументы командной строки или текстовый файл.
- Вывод: консоль или текстовый файл.
- Резервное копирование и восстановление кассовых настроек (с контрольной суммой SHA-256).
- Только стандартная библиотека Python, внешние пакеты не нужны.

> ⚠️ Жадный алгоритм оптимален для «канонических» наборов номиналов (например, 1, 2, 5, 10). Для произвольных наборов (например, 1, 3, 4 и сумма 6) результат может быть неоптимальным.

## Установка

**Требования:** Python 3.8+ и Git.

1. Проверьте Python:
   ```bash
   python --version
   ```
   На Linux/macOS может понадобиться `python3`.
2. Скачайте проект:
   ```bash
   git clone https://github.com/<ваш-логин>/<имя-репозитория>.git
   cd <имя-репозитория>
   ```
   Либо нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив.
3. Запустите:
   ```bash
   python coin_change.py
   ```

## Руководство по использованию

### 1. Интерактивное меню
```bash
python coin_change.py
```
| Пункт | Действие |
|---|---|
| 1 | Рассчитать сдачу: ввести сумму от клиента и цену |
| 2 | Рассчитать сдачи из файла |
| 3 | Показать / изменить номиналы |
| 4 | Создать резервную копию |
| 5 | Восстановить из резервной копии |
| 0 | Выход |

### 2. Командная строка

| Команда | Что делает |
|---|---|
| `python coin_change.py change --amount 78` | Сдача для суммы 78 |
| `python coin_change.py change --input examples/input.txt --output output.txt` | Расчёт из файла в файл |
| `python coin_change.py set-coins 10 5 2 1` | Задать номиналы |
| `python coin_change.py backup` | Создать резервную копию |
| `python coin_change.py backups` | Список копий |
| `python coin_change.py restore` | Восстановить из последней копии |
| `python coin_change.py restore <имя_файла>` | Восстановить из выбранной копии |

Пример:
```
$ python coin_change.py change --amount 78
Сдача 78: 10 x 7, 5 x 1, 2 x 1, 1 x 1 (всего 10)
```

### 3. Формат входного файла
Каждая строка — одно число (сумма сдачи) или два числа через пробел (`оплачено цена`). Пустые строки и строки с `#` пропускаются.
```
# комментарий
78
100 22
```
Некорректная строка не останавливает обработку: в результат попадёт `ОШИБКА (строка N): …`, а код возврата будет 2.

### 4. Резервное копирование
Копии лежат в папке `backups/` (не более 10 последних). Перед восстановлением программа автоматически сохраняет текущие настройки как `*_pre-restore.json`. Если файл копии изменён вручную, восстановление будет отклонено из-за несовпадения контрольной суммы.
