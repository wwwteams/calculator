# Тест-кейсы и результаты проверки

**Объект проверки:** Coin Change v1.0.0 (`coin_change.py`) · **Основание:** `docs/TZ.md` · **Дата проверки:** 23.10.2026
**Среда:** Linux, Python 3.12.3. Все ручные тест-кейсы выполнены реальным запуском программы в чистой копии проекта.

Подготовка: чистая копия проекта (пустая `backups/`), запуск из корня проекта. Команды в таблицах записаны без префикса: `change …` означает `python coin_change.py change …`. Если не сказано иное, `config/settings.json` содержит `{"coins": [10, 5, 2, 1]}`.
Файлы: `examples/input.txt` — строки `78`, `100 22`, `9`, `0` (и комментарий); `examples/invalid.txt` — строки `78`, `abc`, `100 22`, `10 20` (и комментарий).

## 4. Ограничения проверки
- Проверка выполнена на Linux с Python 3.12. Запуск на Windows и macOS (NFR-2) и на Python 3.8 вручную не выполнялся; программа использует только `pathlib`, `os.replace` и стандартную библиотеку, а на Python 3.8, 3.10 и 3.12 тесты прогоняет GitHub Actions.
- Время TC-40 зависит от компьютера.
- Жадный алгоритм не гарантирует минимум монет для неканонических наборов номиналов (TC-12) — это ограничение описано в ТЗ.
